# Changelog

All notable changes to this project are documented here.

## v1.0.0 - 2026-09-23

### Added

#### Backend

* Django 6 starter
* Django REST Framework
* Cookie-based JWT authentication
* Refresh token rotation
* Token blacklisting
* Custom User model
* Environment configuration with `django-environ`
* WhiteNoise static files
* CSP and CORS configuration
* Rotating log files
* PostgreSQL-ready configuration
* Production security settings

#### Frontend

* Angular starter application
* Standalone Angular components
* Angular Router configuration
* Public and authenticated layouts
* Reusable design library
* Reusable shared UI components
* Landing page
* Login page
* Registration page
* Guest page
* Dashboard page
* Authentication guard
* HTTP authentication interceptor
* CSRF initialization and protection
* Authentication state management
* API error handling
* Request state utilities
* Reactive Forms
* Protected `/app` application area
* Responsive application navigation
* Public and authenticated header/navigation designs
* Beginner learning notes
* Angular architecture documentation
* Frontend terminal command reference
